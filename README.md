# UAS Game Asset Semester 4

A water material study for the Universal Render Pipeline. The scene includes a custom water shader, foam texture, and water normal map.

## Open in Unity

Install Unity **6000.0.73f1** through Unity Hub. Choose **Add project from disk**, select the repository root, and let Unity restore the packages and import the assets.

Open [SampleScene](Assets/Scenes/SampleScene.unity) from the Project window. Inspect the artwork and layout in the Scene view.
